# Results

These are the frozen results behind every reported number. **Start from [`docs/paper_results_index.md`](../docs/paper_results_index.md)**, which maps each table and figure to its files.

| Folder | Content |
|---|---|
| [`controlled/`](controlled/README.md) | held-out split of the synthetic repository (1,055 datasets × 3 views); the seeded sweep and the replay are kept separate |
| [`external/`](external/README.md) | 50 external datasets × 3 views, 14 arms; the authoritative index analysis is kept apart from superseded versions |
| `paper_evidence/` | derived tables consumed by the table/figure builders (`analysis/paper/`), including `family_metric_selection_matrix.csv` and `family_metric_utility_matrix.csv` |

The file-level provenance is in `docs/internal_to_release_mapping.md`.
