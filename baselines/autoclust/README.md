# AutoClust

Our implementation under CLUSTOPT's search space: `src/experiments/external_baselines/AutoClust/indomain/` (controlled) and `src/models/Independent_Domain_Benchmark/methods/autoclust*.py` (external). The reported (matched) arms take CLUSTOPT's search space through the runner's `--variant …_same_search_space`; `configs/baselines/autoclust/` belongs to the native adapter, which is not included and not reported. Everything else, including upstream code, pinned commits and rebuild order: [`baselines/README.md`](../README.md).
